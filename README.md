# Morph AI Website

Premium marketing site for [Morph AI](https://www.wemorphai.com) — Shape Shifting Intelligence.

Built with **Next.js 15**, **React 19**, **Tailwind CSS v4**, and **Framer Motion**.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy

This project is designed for [Vercel](https://vercel.com) with zero config. Connect the GitHub repo and Vercel will auto-detect Next.js.
